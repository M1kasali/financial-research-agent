# 金融长文本研究 Agent：计算与补查闭环

后续更新：已完成[同模型四次真实开发对照](core-comparison-2026-09-14.md)，闭环两题均完成，其中一题触发真实补查；全套384项测试通过。仍非独立准确率评测，中间单位推测错误已记录。下文保留本阶段离线实现记录。

## 本轮完成

新增 `CoreResearchEngine`，沿用V45来源证据窗口、已有自由任务问答与引文校验，接入两个受约束分支：

- 问答返回证据缺口：模型提出定向查询 → 范围/重复检查 → 本地检索 → 原V11/V13组件压缩 → 保留旧窗口并追加新窗口 → 再回答与复核。
- 问答返回 `needs_calculation`：模型提出财务任务参数 → 程序检查用户原文与范围 → 已有 `FinancialStatementWorkflow` 检索、绑定、计算 → 模型检查是否覆盖原请求 → 程序直接渲染工具数值、公式与字段来源。

这是一条有限工具集、有限轮数的模型驱动继续执行路径，不是任意工具自主规划；也不是V45最高分生成流程完整复现。

## 计算边界

财务任务参数必须是白名单字段，不允许携带答案、证据ID或正确页码。当前仅支持单份指定文档、年度2000–2099、显式母公司/合并口径和已有指标白名单。

- 年份必须出现在原问题中，不能把2025年的要求改成2024年；同比可包含当年和上一年。
- 原问题必须明确口径，不能把“归属于母公司所有者的净利润”中的“母公司”误当单体口径。
- 指标必须在原问题中出现；总净利润不能代替归母净利润。
- 同比需要明确同比/增长率/增幅表达；比值需要明确比值/之比/斜线及分子分母顺序；暂不把百分比占比混成无量纲比值。
- 跨公司、范围不明、缺年份或口径时返回澄清；提取不能替代已要求的计算。

这些是必要条件检查，不是完整自然语言等价证明。例如“计算同比并解释原因”可能先完成计算，但后续覆盖检查必须阻止把它当成完整回答。该覆盖检查仍依赖模型，不能宣称语义绝对安全。

数值由现有源绑定/确定性计算工具产生，不接受模型重算或改写的最终数值。模型请求匹配复核通过后，再回读所有工具来源并核对字段字符范围，才发布程序渲染的原值、归一化公式、结果和引用。模型复核失败或来源变化时，工具结果仅留在 `financial_result` 审计字段，不进入顶层答案。

工具保留原有受支持年度版式限制、单位/期间声明要求及冲突拒算；本轮没有放宽这些规则。金融工具缺证据时停止并报告缺口，不在同一轮无限重跑。

## 补查与证据记忆

默认最多一次定向补查，Python入口可明确设0–2次。模型只可选择授权范围内的检索查询或停止，不能执行文件、网络或任意代码操作。相同查询和范围不得重复，未带来新的可见证据时停止，不重新消耗答案生成调用。

初轮窗口及引用编号保持稳定；追加新窗口时按原文版本和可见片段去重。旧限制条款/冲突证据不会为腾出位置而静默丢弃。累计最多24个窗口、16,000可见文本字符，结构化元数据及提示另计入完整请求Token预算。容量不足时保留旧材料并停止无进展扩展。

缺口仅影响补查和证据窗口聚焦，交给回答/复核模型的原始用户问题不改变。旧候选、复核和证据包保留在 `round_history`，不把未通过候选当成已知答案。

## 共享预算和运行入口

`financial-agent answer` 默认使用新闭环；加 `--no-follow-up` 回到上轮单次问答，可用于后续同模型对照。

默认仍不加载密钥、不开启真实请求。仅显式 `--execute --output-dir 新目录` 允许调用当前项目配置的Qwen3.7 Flash。默认闭环预算：

- 最多16次逻辑工具调用；财务子流程自身最多12次，且内部每一步也先检查父任务同一额度，不重置预算。
- 最多8次HTTP尝试，含问答、查询决策、复核、参数解析、请求覆盖检查及HTTP重试。
- 最多200,000估算Token预留、0.25元批次费用预留；费用守卫沿用已记录价格快照，实际服务商账单为准。
- 单次输出最多1600 token，单请求45秒超时；未知请求停止，不自动重新执行。

`--no-follow-up` 保持1次检索、4次HTTP尝试、100,000估算Token上限。切换模式没有执行真实模型效果验证，不得直接宣称默认闭环更优。

没有添加自动持久化恢复，整个新问答闭环仍是内存单次执行，输出JSON/Markdown和真实执行时的费用日志。原ResearchRuntime的SQLite恢复机制未被改写，但不自动适用于此入口。

## 验证结果

全套 **381项测试通过**，Ruff通过。新增24项测试覆盖真实确定性工具接入、共享预算、请求参数错配、缺年份/口径、单体口径、比值顺序、归母/总净利润混淆、多意图覆盖拒绝、模型预算耗尽、源变化、保留旧证据、越范围补查、重复/无新增证据停止及超时停止等。另通过全部既有财务流程与问答回归。

检查中发现并修复了事实年度为字符串、任务年度为整数导致单体提取渲染为空的问题；现在无匹配年度事实不得以answered发布空答案。
