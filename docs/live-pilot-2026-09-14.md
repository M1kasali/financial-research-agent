# 首次真实 Qwen3.7 Flash 开发实验

## 结论

真实 API 已联通，但动态研究流程本轮 **0/2 完成**。两题都在 12 次工具尝试后预算停止，未产生已核验答案。不能把 HTTP 成功当作 Agent 成功，也不能把本轮完成数称为准确率。

实验目录：`experiments/runs/live-pilot-20260914T030022Z-bd08b87f/`。
各题 `*-dynamic.json` 保存实际运行结果，`*-fixed.json` 为固定流程对照，SQLite 保存原始模型 JSON 响应与检查点；`manifest.json` 保存公开问题和范围，`spending.jsonl` 保存逐次预留和用量。

## 范围与成本

- 经用户批准使用当前项目 `.env` 的密钥，仅请求官方北京兼容接口及 `qwen3.7-flash`；未读取历史队伍密钥。
- 同一 BYD2025 开发文档的两道独立任务：合并营业收入同比、母公司净利润。不是连续追问实验，不是留出集，不含 B 榜 gold。
- 模型自行输出计划和工具 JSON；执行器做白名单、文档版本、口径及预算校验。不是模拟响应，也不是 HTTP 原生 function calling 实验。
- 每题最多 16 次模型请求（含重试）、12 次工具尝试、300,000 估算 token 预留；每次生成最多 1,600 token；批次合计 1 元估算预留上限。
- 28 次实际请求全部成功且都有 usage，无重试、无未知用量。报告总 token 为 107,104。
- 按已报告输入/输出 token 与公开原价计算约 **0.0235058 元**，未计缓存或赠额折扣；服务端账单为准。批次保守预留累计 **0.6941424 元**，这不是实际支出。
- 价格来源：[阿里云 Qwen3.7 Flash 官方文档](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)，核对日期 2026-09-14。预留按北京最高档输入 1.2 元/百万、输出 4.8 元/百万，不退回预留；UTF-8 字节加开销仅为保守代理，不是精确分词或服务端账单硬上限。

### 同比题

模型初始计划能够拆分“原值与口径确认→同比计算”。首次检索已命中第126页合并利润表，同时返回第134页公司利润表。

第4步却把第134页当作 `expected_scope=consolidated` 的主证据，把第126页作为会计政策上下文，触发 `Requested scope conflicts with statement title`。随后读取多个候选、进行一次上下文扩展，又在第12步重复同一错误绑定。没有成功绑定事实、计算或核验答案。

### 净利润题

初始计划把“母公司净利润”引向母公司/合并资产负债表，并把“净利润”和“综合收益总额”当成可替代指标；这是明显的任务语义错误。第3步还尝试操作尚未就绪的子目标，被依赖检查拒绝。之后重复同一检索并反复发出无新状态的读取请求，第8至12步被循环检查拒绝。没有进入成功绑定、计算或答案核验。

## 工程定位

已经证明：真实模型参与了计划和工具选择；真实 usage 能落盘；预算、口径和目标依赖检查实际生效；失败没有被伪装成完成。

尚未证明：稳定自主研究、答案质量、跨文档能力、连续记忆、真实模型的核验质量、历史比赛成绩复现。本轮不能据此宣称“成熟金融 Agent”。

除了模型选择错误，代码检查发现可改进点：当前 observation 只保留最近一次工具正文，证据目录主要是引用元数据；最近动作不带旧 observation，拒绝事件也不保留原错误 action。跨步骤维持证据语义、记住失败原因的支持不足。重复检测又把整个证据集合纳入签名，新增无关证据后可再次执行相同读页或错误绑定。上述为代码与轨迹支持的改进假设，尚未通过消融确认其因果贡献。

## 下一轮优先级（尚未实施或付费重跑）

1. 金融任务约束：明确净利润/综合收益总额不可互换，利润表/资产负债表区别，母公司/合并口径不可混用；在保持自由拆分的同时校验计划是否偏离用户指标。
2. 证据工作记忆：保留已经读过的报表标题、口径、期间、单位缺口及引用，保留失败 action 和修复提示；避免模型只能在长哈希 ID 之间选择。
3. 把已可运行的固定财务核查流程封装为较高层工具，由模型自主决定调用、补查和组织结论；不要求模型每次重新拼装所有底层读页/绑定操作。保持来源校验，不以模型猜测放宽计算条件。
4. 先以本轮失败轨迹添加离线回归，再另行确认下一轮真实实验范围；保留本轮结果，不覆盖失败，不靠无限重跑筛选成功。

## 运行与安全

新增 `scripts/run_live_pilot.py`。不带参数只输出计划，不发送请求；`--execute` 才显式加载本项目 `.env` 并执行两题。每次执行都会创建新批次并可能计费，不应无授权重复运行。

批次费用日志独占新建并在请求前 fsync；拒绝重新打开同一日志重置额度；没有自动续跑。底层任务支持检查点，但本入口没有实现跨进程批次费用恢复，因此不可绕过入口手动续发。未知或失败请求的预留不退回。请求及恢复记录不保存密钥或 Authorization，报告和数据库应保留在可信本地目录，不提交到远程。

新增费用检查7项测试，与原测试合计 **309 项通过**；新增代码 Ruff 检查通过。
