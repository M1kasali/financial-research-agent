# 可运行的固定财务研究流程

## 从结构化问题开始，不指定正确页码

新增 `FinancialQuestion`、`FinancialStatementWorkflow` 和 CLI `financial` 命令。

输入只有指定文档版本、年度、母公司/合并口径、指标，以及提取/同比/比值操作。系统据此形成明确问题，派生报表标题查询，从检索候选中读取报表，再补查会计声明、严格绑定字段来源、执行计算，最后输出结果与失败原因。不是自由文本问题解析器，当前仅支持单份指定文档。

所有查询只依据公开任务参数，不读取人工草案、标准答案、目标chunk ID或正确页码。文档ID是用户指定范围，不是隐藏答案定位器。来源由检索返回后才获得其引用ID。

控制器仍是固定流程，不能称为自主规划Agent。它提供可以实际运行的财务功能及后续模型驱动流程的可复现对照基线。

## 运行方式

在项目根目录执行，例如核查给定语料的合并收入同比：

```bash
.venv/bin/financial-agent financial \
  --chunks ../AFAC赛题四_团队方案_v1_20260712/processed_data_v1/chunks.jsonl \
  --doc annual_byd_2025_report \
  --year 2025 \
  --scope consolidated \
  --operation growth_rate \
  --metric 营业收入 \
  --output-dir data/local/my-revenue-review
```

输出目录必须是新目录，不覆盖已有报告。默认最多12次逻辑工具调用，可通过 `--max-tool-calls` 指定；`read`、补查、绑定失败和计算都计入，读过的来源可在本次任务内复用。没有真实模型请求，不加载 `.env`。

其他支持用法：

- 母公司净利润：`--scope parent --operation extract --metric 净利润`。
- 经营现金流/合并净利润：`--scope consolidated --operation ratio --metric 经营活动产生的现金流量净额 --denominator-metric 净利润`。
- `--scope parent` 下不能把“归属于母公司所有者的净利润”作为母公司单体利润。

输出 `result.json` 保存版本、查询、每步参数和返回、绑定事实及计算来源；`report.md` 展示数值、单位、公式、逐字段原文及物理页/字符范围。CLI退出码0表示受支持流程完成，3表示流程未完成，2表示命令参数/文件等错误。完成状态不代表人工批准或实际法律/财务真实性核验。

## 防错与当前边界

- 同任务发现多个不同报表值或会计单位声明时停止；不能悄悄挑选“可成功”的那个。
- 只检查已检索候选，不承诺排查全文所有冲突。报表候选最多2个、会计声明最多3个；超出要求复核。
- 每个引用最多读12000字符；预览缺少识别标记、截断版式、错误年份或未知结构可能导致停止，不能用启发式补齐。
- 复用现有严格绑定与计算工具，母公司/合并混用、源文本变化仍拒绝；最终来源完整性检查失败则撤下数值与计算结果。
- 本固定流程只做进程内执行、任务内缓存和JSON事件输出，不支持自身暂停恢复；已有模型运行时的SQLite恢复路径保持独立，不能混称。
- 当前查询结构是显式参数，不把结构化输入称为任意自然语言理解。
