# 批次 B：研究执行循环初版

## 本次实现及边界

已建立模型决策驱动的运行机制；本次仅使用假模型验证协议和执行链，没有发送外部模型请求，也没有评价真实模型的自主规划质量。

- `runtime.py`：模型生成有依赖的子目标，复用原 LogicRAG 图结构；每步依据当前证据、事实、计算、核验反馈和预算选择动作。
- `policy.py`：统一的 JSON 决策协议，供规划、行动及审阅使用。模型不能执行 Python、Shell 或任意表达式。
- `research_tools.py`：复用原 BM25 检索、数值事实账本、白名单计算 DSL；不是把整个最高分问答流程作为单个黑盒。
- `simulation.py`：明确标注的假模型。与生产运行时共用接口，但假模型的规则不进入生产控制器。

工具包括 search、read、extract、calculate、verify。执行器不规定它们必须按固定顺序调用；依赖就绪、文档范围、来源存在性、计算口径与预算由程序约束。模型可补查、增加子目标、询问用户或提出结束。**计划调整当前仅支持增补目标，不能删改原目标**，最多 8 个子目标。

应用额外建立 `overall` 目标，要求在子目标完成后核验整个原始用户请求，防止只完成模型拆出的部分问题便结束。该机制减少遗漏风险，但审阅仍是模型判断，不是确定性的语义正确性证明。

## 数值与证据约束

- 候选事实绑定文档版本、chunk、原文哈希；事实 ID 与内容绑定。原始解析元数据在建立版本时快照，避免旧索引后续修改元数据改变提取输入。
- 程序计算只接收已提取的事实 ID，输出原始操作数、表达式、显示舍入值、来源链和公式政策 `annual-cny-v1`。
- 当前货币单位：元/千元/万元/亿元，统一到基础金额；币种须从原文明确识别人民币。主体目前需要原始解析元数据 `financial_context.entity` 且该主体名出现在原文；不从 doc_id 猜主体。
- 合并/母公司口径需有明确表名；季度、混合期间、混合币种或口径不清会拒算。原始数据若缺上下文，允许提取候选事实，但不会伪造字段凑齐计算。
- 同比仅支持同一主体、同一指标的相邻年度、正基期。差值和大小比较要求同期间同指标；比值要求同主体同期间。零分母、非有限值及同主体同指标同期间的冲突值受拦截。
- 这不是完整财务口径解析器：历史语料缺主体等注释时，仍需增加可靠的解析/补证机制；抽取候选本身也可能有误，需原文审阅。
- 引文核验仅从已检索且在任务范围内的证据取正文，长文本显式标记截断。最终交付前再次检查已保留引用的哈希。

## 预算、终止和结果

规划、每一步决策、核验、重试共享模型请求预算。工具调用（含非法尝试）计次。每次真实或模拟传输前进行保守 Token 预留；UTF-8 字节估算不等于精确 Token 或费用上限，未知消耗不退款。

返回状态：`completed`、`partial`、`needs_input`、`failed`。预算不足保留已有结果与未完成目标；不把错误当数值答案。无新增状态的重复调用被拒绝，循环有额外步数上限。来源变动导致失败并清空已验证回答。

结果 JSON 包含子目标回答、引用、事实、计算、动作/工具结果事件和逐次模型请求账务。当前只存内存；实验脚本将完成结果写入独立报告目录，**不等于检查点持久化或断点恢复**。未实现连续追问、跨任务记忆、用户取消和正式报告渲染。

## 已执行验证

1. 119 项离线测试通过（原 65 项 + 新增 54 项）。包括 DAG 异常、整体核验门禁、核验后补查、越域工具请求、虚构引用/计算 ID、模型禁用、预算不足、重试计费、超时不重试、单位与口径、零/负基期和冲突值等。
2. 两个合成集成案例：营业收入 100 万元到 120 万元，经原 DSL 得出同比 20.00%；合同首轮缺少例外，假模型审阅返回缺口后更换检索，最终同时引用通知条款和例外。
3. 真实语料执行链：68 份文档、8,925 个 chunk；财报、合同、保险、监管、研报各取 2 题，共 10 题。假模型驱动规划、真实检索和回读，然后明确停止；不生成答案，不计算正确率。
4. 共 59 次假模型 attempt、30 次工具调用，外部模型请求 0 次。集成实验约 26.81 秒（含全库索引构建，不能当真实模型端到端时延）。
5. Ruff 检查通过；106 个迁入的算法/旧测试文件仍与来源哈希一致。
